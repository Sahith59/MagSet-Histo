# Registered UNI2-h case-level SVC comparison

Registered November 17, 2026, before this family's fitting or validation scoring. This is **one bounded standard readout comparison**, with RBF SVC as the fixed primary and linear SVC as its matched control. The question is whether fitting the deployed case/magnification-subset target with a nonlinear margin helps beyond the same linear margin learner. [Exact configuration](../configs/breakhis-uni-case-svm-v1.json).

Training and validation evidence motivates the prediction-unit question: the field-supervised neural models fit their training surrogate while validation typing losses remain high, and subtype predictions disagree within specimens/views. These observations do not prove incorrect field labels or inadequate tissue content. Previous whole-case mean/attention, case-logistic and UNI2-h field-logistic negatives argue against assuming that case supervision or a different learner will resolve generalization. No new encoder or million-parameter learner is justified by this registration. [Training/validation diagnosis](reviews/MATCHED_TRAINING_DIAGNOSIS.md), [whole-case negative comparison](BREAKHIS_CASE_MIL_RESULTS.md), [UNI field-logistic negative result](BREAKHIS_UNI_LINEAR_RESULTS.md).

The completed fixed-router specialist family failed its registered **validation** progression screen: UNI2-h improves macro F1 from .577663 to .590347 but lowers accuracy from 79.61% to 77.25%. Its already-viewed retrospective test result does not select or justify this new method. Retain P and the specialist as fixed contextual references. No coefficient, kernel, gamma, C value, threshold, representation or choice of subset in this family may be changed because of those test outcomes.

## Two kernels and one finite budget

Both arms use `sklearn.svm.SVC`; the linear arm uses `kernel='linear'`, rather than the different `LinearSVC` estimator. Each has exactly four shared binary/malignant C choices: **0.1 / 1 / 10 / 100**. Set `gamma='scale'`, `class_weight='balanced'`, `probability=False`, `decision_function_shape='ovr'`, `break_ties=True`, `random_state=812`, `tol=1e-4`, `shrinking=True`, `max_iter=100000`, and `cache_size=256`. Save the resolved gamma separately for each fitted head; it depends on that head's unweighted fitting-row variance. The pinned library defines these semantics. [scikit-learn SVC documentation](https://scikit-learn.org/1.6/modules/generated/sklearn.svm.SVC.html).

Every fitting specimen contributes all 15 masks with sample weight **1/15 once**. Automatic balanced class weights supply the inverse-class factor; do not apply it again manually. Binary sample weights sum to 49 and malignant sample weights sum to 35. After class weighting, total mass per binary class is 49/2 and per malignant subtype is 35/4. Only true-malignant fitting specimens train the four-type head. Both heads share the same C for a candidate.

Eight candidate pipelines fit **16 head estimators**. Each four-class SVC internally fits six one-versus-one problems, so the complete family contains **56 binary optimization subproblems**. Its exposed four-column OVR decision function combines pairwise votes/confidence; it is not four separately fitted OVR margins. The two kernels receive identical input transformations and four selection opportunities. No gamma grid, learned projection, calibration search, new seed, fold or post-result expansion is included.

## Decisions, scores and selection

Route a case/subset as malignant when its binary margin is **at least zero**, including an exact tie. On a malignant route choose the first maximum of the four OVR scores, in ductal/lobular/mucinous/papillary order. Produce reporting scores with `b=expit(binary_margin)` and a stable softmax of the four OVR scores at fixed temperature one, composed as `[1-b, b*q]`. These are **uncalibrated normalized scores**. Each case/subset is one fused input; there are no field probabilities or additional probability pooling. Require the numerical score route to agree with the authoritative margin route, or fail closed. Do not nudge near-zero scores to make a check pass.

`probability=False` avoids SVC's internal probability-estimation cross-validation, which would otherwise split dependent masks without the required specimen/group control. No external calibrator is fitted. A binary calibrator is a separate possible question: the observed perfect validation ranking does not establish a transferable threshold fix, and calibration cannot resolve malignant typing. This family tests both decisions with a fixed common budget.

Select each kernel's first maximum validation mean-15 **final-five macro F1**, including all five labels. Save all eight candidate outputs and negative outcomes. The prospective development progression screen requires the selected RBF arm to improve macro F1 by at least **.02** with nondecreasing accuracy versus the separately selected linear arm. Report binary scores and every class recall. A favorable retrospective test does not override a failed validation screen.

Save/hash each fitted bundle and reload it. Before either retrospective test query, require validation margin agreement within absolute **1e-10**, exact routed decisions, and successful normalizer/input persistence checks. Seal **both** selected candidates, all candidate artifacts, source/config/cache/audit bindings and reload receipts in a shared gate. Then query only the two selected pipelines on the unchanged 16-case role, retaining all 15 subsets and the original study's results. Those two outputs are retrospective reused-development follow-up, not fresh clinical confirmation.
