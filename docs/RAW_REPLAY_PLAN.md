The existing checks establish source/configuration/cache hashes, completed scheduler runs, selected-checkpoint validation replay, disjoint identifier groups and independent saved-array score calculations. They do not independently re-execute every reported model from raw image files. [Forensic audit](reviews/MATCHED_PROOF_AUDIT.md).

The new CNN/Swin proof reopens all 1,704 original test PNGs, checks each byte hash, checks filename/directory labels, independently reconstructs the three crops and requires exact agreement with the original shared pixel cache. The model receives these newly decoded pixels. It rebuilds the unchanged architecture from frozen producer `a6e6a54e4fac090051837df17b0dea14efca3bb3`, loads only the previously selected weights, and independently composes and pools probabilities and computes the scores. Every case/subset decision must match; field probabilities must match within the original 1e-5 tolerance and headline metrics within 1e-12. The architecture builder is shared; this is a separate execution and input/scoring path, not an independently rewritten backbone.

The [proof configuration](../configs/breakhis-matched-raw-replay-v1.json) pins the original comparison, selected test receipts, field archives, software versions and A40 hardware. Each model uses one GPU; at most two run together, with 30 minutes per task. Six lightweight checks cover both image geometries, tampering, labels, probability composition and case pooling before cluster execution. All outputs go to a new proof directory. No fitting, checkpoint choice, parameter tuning or canonical result modification is allowed.

A separate Midnight proof will reopen and re-encode **all 7,909 fields**, including the 4,621 fitting-support fields, through the original frozen FP32 reader. Four magnification shards can run with concurrency two. Its own raw pixel construction and CLS-plus-patch-mean readout will be compared with the original cache at the already registered feature tolerance. A CPU checker will rebuild fitting-only support statistics from the replayed features, replay all four validation temperatures and the fixed selected test setting, and require identical case decisions and scores. This closes the support-feature execution gap that a test-query-only replay would leave. These verification tolerances do not change the reported model, selected setting or original saved outputs. This full Midnight proof remains planned until its actual receipts pass.

These executions verify the same already evaluated images and selected models. They are not new performance estimates, new model candidates or an independent clinical cohort. All failures are retained; a failed replay must be diagnosed without relaxing its registered acceptance criteria to obtain a desired score.
