# Capstone modelling review

November 14, 2026. Independent source/document review; no training, weight download, cluster submission or new predictions. Recommendation is prospective, not measured improvement. Reviewed the project instructions, README, plan, related work, private handoff/operating rules, original-material review/walkthrough, supervised implementation/configuration, diagnosis and reference audit.

The defensible urgent capstone is a reproducible BreakHis study with an explicit prediction unit and honest generalization limits. It does not require a novel network or a high score. The existing frozen reference is the retained model. The completed ResNet and adaptation runs are useful negative results, not evidence that all conventional image classifiers fail. Neither more epochs nor another backbone is presently the strongest next action.

## Ranked hypotheses and checks

| Rank | Hypothesis and evidence | Cheap check and what it can decide |

| 1 | Independent subtype coverage limits transfer. Every fit has only one adenosis and one phyllodes case, despite many fields; phyllodes training performance is near perfect and validation recall remains zero in both backbone families. This is the strongest observed limitation, but does not prove its sole causality. | Reuse the audited role/class counts and existing case-level predictions. Tabulate distinct fitting cases versus errors, without fitting or selecting a model. This decisively confirms coverage, not the performance attainable with more patients. New crops, augmentation and class weighting cannot create new independent cases. |
| 2 | Canonical input reduction may suppress useful morphology or peripheral context. ResNet warps a700×460 field to224×224. A single controlled frozen-encoder multicropping comparison below can test an alternative representation, but cannot separately attribute gains to resolution, locality or averaging. |

No evidence identifies frozen BN, canonical input reduction, ImageNet initialization, pooling or a software bug as the sole cause. Batch size 32 is not itself proof that BN statistics should be updated. A larger batch is not a replacement for more independent cases. The successful provenance/replay audits are evidence of implementation consistency, not clinical validity.

## Task and model-selection assessment

The current task is eight-subtype **provider-case** classification from any of the 15 nonempty subsets of four magnifications. Cases have unpaired sets of fields; equal filename sequence numbers do not supply registration. Equal view probability pooling is a reasonable standard reference. Linear feature averaging and logit averaging are algebraically identical for a fixed affine head; diagnosis already checked that identity. More elaborate pooling needs a matched encoder, roles, seeds and tuning budget, and existing neural fusion comparisons provide no compelling immediate rescue.

Selection is especially fragile: eight validation cases, one per class, make accuracy change by one eighth for an individual full-view trial; subset/trial averages obscure that discreteness. The 15 subsets and five overlapping trials are dependent observations. Selection among four epochs is legitimate development selection, but the same development cases have repeatedly informed pipeline choices. A fresh configuration is not a fresh evaluation cohort. All 82 cases have entered development somewhere, so no untouched BreakHis confirmation claim follows from a new split or previously excluded role.

Keeping the ResNet's trained image head was correct for the registered complete-pipeline reference; replacing it posthoc with a winning alternative would create another selection round. Comparing ImageNet ResNet to frozen Phikon does not isolate pretraining domain: architecture, adaptation, representation and objective differ. Phikon's pathology provenance and unresolved cohort overlap must remain documented.

## One recommended capped experiment, if improvement work continues under the current scope

Test **one fixed frozen Phikon field representation with its original canonical feature and four quadrants**, paired with the original canonical-input control. This tests one alternative allocation of spatial evidence without fitting another large backbone. Finish the capstone report regardless of outcome. This is an exploratory conventional preprocessing comparison, not a new method or a final clinical test.

- **Task/roles:** retain eight subtypes, all four magnifications, all 15 subsets, and the exact ten existing 46-fit/8-validation/28-excluded memberships. Encode only the union of existing fitting/validation fields needed for these runs; never predict excluded-role cases within a run. Derived crops retain original field/case/role identity. Do not pair fields across magnifications.
- **Control:** original accepted frozen Phikon cache: RGB field processed by the pinned official BitImageProcessor, bicubic shortest-edge resize to224 followed by central224×224 crop and fixed ImageNet normalization. Reuse only after exact provenance checks. The cached feature does not encode the entire original field.
- **Candidate:** divide the original field at integer midpoints into four nonoverlapping quadrants, apply the identical official Phikon processor independently to each quadrant, then encode with the identical frozen encoder. Field feature = float32(0.5 × float64(original cached feature) +0.5 × float64 mean of four quadrant features). No crop search, stain fitting, test-time augmentation or learned crop attention. Raw quadrant boxes cover every original pixel once, but each quadrant processor subsequently center-crops; encoded quadrants do not retain every raw pixel. The candidate changes locality, effective physical resolution and peripheral coverage together, so it cannot isolate a compression effect.
- **Head/control budget:** refit both arms with the existing masked-mean-plus-availability logistic pipeline, fitting-only case-mean normalization fitted separately per arm, class balancing and equal subset weights. Fix C=0.01 for both arms before new outcomes, using the existing implementation/solver/max-iteration policy; verify convergence. This is deliberately one fixed setting, not a claim of optimal C. Exactly20 CPU head fits (two arms × ten roles); no validation-selected regularization grid. Also report the original retained frozen reference separately, since its historical C selection differs.
- **Selection budget:** one representation candidate, one fixed C, zero checkpoint selection and no follow-on crop/weight/C/encoder alternatives. For consistency use the existing descriptive screen: candidate minus matched control mean-subset macro F1 ≥0.02 on both arrangements and positive phyllodes recall on both. Passing is exploratory evidence only. Failure ends this experiment; do not widen the search.
- **Report:** both arms in every trial, mean/all-view/worst-subset macro F1, accuracy, per-class recall, probability score, and distinct case support; fitting results separately. Do not select only favorable views or trials. Retain all hashes, transforms, normalization state, feature caches, models and predictions. Preserve the existing baseline unless the registered comparison is fully checked.
- **Compute:** at most four additional encoder forwards per unique eligible field, reusing its original thumbnail. For the full release this upper bound is31,636 additional field-sized forwards; the eligible union may be smaller. No backbone training or new weights. First run a tiny fitting-only transform/inference smoke to measure throughput/memory, then request a bounded scheduler allocation based on that measurement, at most four concurrent extraction workers under current cluster policy. Do not assert wall time from the ResNet training timings. A failed consistency smoke stops production without a scientific recipe change.
- **Acceptance checks:** exact crop coverage and pixel provenance; role disjointness including derived data; no fitted preprocessing on validation; fixed dimensions/canonical label order; all15 subsets; permutation and missing-view invariance; finite probabilities; normalizer/model save/reload; exact expected path coverage; independent arithmetic replay. Synthetic/unit success is not performance reproduction.

This experiment can provide a bounded answer to whether one fixed original-plus-quadrant representation helps under the existing development regime. It cannot repair rare-class support, prove that compression caused the original failures, or manufacture untouched confirmation data.

## Whether to reproduce the EfficientNetV2B0 notebook

Do not silently replace the all-magnification case task with the original40× single-image task. The notebook is a different endpoint and uses image splitting without enforcing patient separation; its reported93.73%/94.99% scores are historical saved outputs, not our targets. Its selected evaluation data also guided model selection. These specific code findings do not imply that all papers leak or that every published high score is invalid.

If Professor Dong explicitly defines the capstone as a corrected notebook reproduction, choose that **instead of**, not in addition to, the proposed preprocessing experiment. Register a separate image-level eight-class track, retain group-separated roles across all views/derived images, and evaluate all four magnifications separately as required by the current project instructions. A40× result can be the historical comparison panel. Start with ordinary EfficientNetV2B0 without either custom attention module; fixed published/notebook preprocessing and a declared bounded training/selection schedule, with pinned weights/environment, would be a conventional baseline rather than an exact score reproduction. Preserve the current case/subset track as a separately reported project result. Do not copy the notebook's image split or select among both custom heads to chase its score.

The non-local block and one-step ConvLSTM gate are not needed for a defensible capstone. Their established mechanisms, implementation differences and very different parameter counts complicate interpretation. A corrected EfficientNet experiment cannot currently promise better transfer than the completed ResNet reference. Under the existing scope, the frozen representation comparison above is the smaller and more targeted next experiment.
