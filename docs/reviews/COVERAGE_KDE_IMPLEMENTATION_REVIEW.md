# Three-crop coverage KDE: pre-execution implementation review

November 16, 2026. Read-only review of [coverage_five.py](../../magset/coverage_five.py), [coverage_collect.py](../../magset/coverage_collect.py), the frozen feature producer/auditor metadata and the unchanged kernel path. No cohort fitting, scoring, encoder execution or jobs were performed by this review.

**Verdict:** no remaining implementation blocker found in the reviewed path after adding the unchanged `field_five.py` hash to the reference comparison. The classifier registration is deliberately **unbound**: producer revision, accepted full-feature audit hash and four exact shard bindings must be populated only after the actual feature audit succeeds. The current skeleton must reject execution; that is the intended guard.

The new loader first verifies the original Midnight registration `07b14d63…` and accepted center caches through `--center-cache`, preserving original provider identities, labels, roles and all four magnifications. It then requires the registered coverage extraction config `6caada1c…`, the exact full-audit file hash, accepted audit status, feature-producer revision, manifest, encoder and four shard receipts. Producer, auditor and loader agree on metadata names and component-file naming. Per shard, fused NPZ, metadata JSON and component NPZ byte hashes are bound, along with original-center cache hashes, source-file hash, encoder, full-image count and `smoke_limit: 0`.

The full feature audit reconstructs each descriptor as the float64 mean of left, previously accepted center and right embeddings, followed by one float32 cast, and checks exact original-path order and shape. The classifier subsequently trusts the **hash-bound accepted audit** and immutable shard bytes; it does not claim to independently re-run crop images through the encoder. `load_bags` rechecks complete original-field coverage and provider membership. Three crops remain **one field**, not three independent samples.

Coverage execution delegates to the existing KDE run with the explicitly loaded new bags. The only kernel-run refactor is its optional supplied-input argument; the default old path is unchanged. Support-only equal-case centering, float64 L2 normalization, same-view class/case/field weights, whole-query-case exclusion from both support and centering, four shared temperatures, joint field probabilities and hard routing remain unchanged. The reference now compares hashes for data, split logic, metrics, bags, kernel math **and field pooling/hard gating**. All six reviewed files match the accepted single-center comparison hashes. The old immutable experiment remains historical evidence.

The collector reuses complete KDE replay: ten role arrangements, both arms, four candidates, 80 support-model records and 160 fitting/validation prediction archives containing 64,800 dependent records. It reconstructs predictions and earliest maximum-macro-F1 selection from the new bags, rejects incomplete/extra artifact matrices and compares against the hash-bound single-center KDE reference. Class labels, original roles and method hashes must agree; encoder/cache descriptors may differ because that is the registered intervention. Public comparison objects retain hashes and summaries; raw paths, provider identities, component features and support records remain private.

This is a controlled **input-coverage** change, not added fitting data or a new classifier mechanism. The overlapping crops cover the resized width but weight central tissue more heavily; averaging embeddings can also dilute focal evidence. Each arm still gets four temperature choices. Classification itself has no new encoder forwards, while extraction adds **15,818 production crop forwards**, plus the separately reported technical smoke. Those costs must remain separate in reporting.

Actual feature-audit and classifier output acceptance remain pending this source review. Any resulting score is reused provider-case development validation, with the existing rare-case and identity limitations. This review supplies no accuracy result, new method claim or 94–95% guarantee.
