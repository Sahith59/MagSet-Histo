## Loss and optimization assessment

The prescribed weights are correct. With N = 46, the direct class weight is `46/(5*n_class)`, router group weight `46/(2*n_group)`, and malignant specialist weight `46/(4*n_subtype)` with zero benign contribution. Each component's total case-weight mass over a full epoch is 46. The specialist numerator is averaged over all fitting cases, so using 35 in its numerator or adding another 46/35 correction would be wrong. The half-router/half-specialist combination gives the declared total epoch mass without claiming equivalent gradient trajectories.

The source uses unreduced losses, all 15 masks, and the fixed denominator 4 × 15 = 60, including the final two-case batch. Epoch logging multiplies batch values by the configured four-case denominator and divides by the actual epoch case count, recovering the stated weighted numerator divided by 46 × 15. It does not silently give the last two cases twice the base gradient scaling. Specialist loss uses true malignant fitting labels only. In an all-benign batch, the full loss remains connected through the binary/shared graph while specialist parameters retain `grad=None`; AdamW therefore skips their unsupervised decay and moment update.

The optimizer explicitly contains the selected backbone parameters from initialization even while their `requires_grad` is false. This avoids the common failure where a warmup-only filter permanently omits the later adaptive backbone. The same optimizer survives transition, preserving head moments. The learning-rate formula has the declared endpoints: epoch 6 factor 1 and epoch 50 factor 0.1; the single smoke adaptation epoch uses factor 1 without a degenerate cosine denominator.

`set_phase` separately controls gradients and evaluation mode: selected late affine parameters become trainable while every BN running buffer stays frozen. It keeps early parameters frozen and does not convert late affine parameters into a permanently frozen BN wrapper. The inspected state fingerprints and per-epoch whitelist checks test the intended boundaries. Nonzero pre-clip group gradient norms were added during review because `grad is not None` plus changed parameters alone would not exclude an AdamW decay-only update. Actual pinned timm module/parameter counts and the smoke receipts must establish that the intended partition is present and receives fitting gradients.
