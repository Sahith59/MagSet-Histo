# Frozen Midnight five-category classifier comparison

This study evaluates the frozen Midnight-12k representation after complete feature-cache verification. It uses the same BreakHis images, original-eight-derived case roles and five-category labels as the accepted Phikon comparison. Each run has 46 fitting cases, eight validation cases and 28 excluded cases. The malignant specialist fits the 35 malignant fitting cases. All four magnifications and all 15 nonempty input combinations are evaluated.

Two readouts are declared before classifier fitting. The case readout averages image features within magnification, applies the common fitting-only field-moment normalizer, averages available views and appends four availability indicators. It uses the accepted class-balanced case/subset logistic objective. The field readout standardizes individual fields with the same fitting-only normalizer, appends one-hot magnification indicators, and uses class/case/view-balanced manual image weights. Its two-step inference pools per-field joint probabilities within views and across available views. These are the same readout definitions already tested with Phikon.

Both readouts have a direct five-category arm and the requested benign/malignant then four-malignant-type arm. The heads are L2 logistic regression with lbfgs, tolerance1e-4, maximum2,000iterations and training seed812. Each complete arm chooses from C=[.01,.1,1,10] by maximum mean15-subset end-to-end five-category macro F1, choosing the earliest candidate on a tie. Both hierarchy heads share C. The routing threshold is0.5, with malignant ties. There are ten paired runs per readout,20 in total, with240 individual head fits and160 complete candidate pipelines.

The classifier configuration will bind the generated four NPZ and JSON hashes, frozen feature-producer source, extraction configuration, pretrained revision, manifest and protocol before any classifier fitting. The dataset, label order, role supports, optimizer, readouts and selection budget are already fixed. The full-cache audit produces zero classifier fits, image decodes or new encoder forwards.

Complete verification covers all20 paired runs,160 candidates,160 saved model archives,320 prediction archives and129,600 dependent case/subset records. Existing independent case and field coefficient/probability/metric/objective verification is reused. Each readout reports its own comparison against the fixed earlier Phikon two-step reference. The descriptive screen requires at least+.02mean15macroF1, no lower accuracy and positive recall for every class on both validation arrangements. Case-versus-field and direct-versus-dual differences accompany all outcomes.

Allocations are four CPU cores,24GB and45minutes per paired run, with at most four concurrent tasks. All82 provider keys have entered development, and clinical patient identity remains unresolved. The resulting measurements describe reused provider-case development validation. Classifier performance on the current task still needs measurement.
